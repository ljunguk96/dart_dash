# dart_dash

이미지 파일을 넣으면 자동으로 하나의 PDF로 합쳐주는 웹 앱입니다.

## 사용법

`index.html` 파일을 브라우저로 열면 바로 사용할 수 있습니다 (별도 설치나 서버 불필요).

1. 이미지를 드래그 앤 드롭하거나 클릭해서 선택합니다.
2. 필요하면 목록에서 드래그로 순서를 바꿉니다.
3. "PDF로 변환 & 다운로드" 버튼을 누르면 이미지 순서대로 페이지가 구성된 PDF가 다운로드됩니다.

모든 변환은 브라우저 내에서 처리되며([jsPDF](https://github.com/parallax/jsPDF) 사용), 이미지가 서버로 전송되지 않습니다.
