# 단어대시 (dart_dash)

매일 영단어 20개를 학습하고 퀴즈까지 풀 수 있는 정적 웹사이트입니다.

## 기능

- 날짜 기준으로 매일 새로운 20개 단어 세트를 자동으로 보여줍니다 (단어장이 순환됩니다).
- 플래시카드 형식의 학습 화면: 카드를 클릭하면 뜻과 예문이 보입니다.
- 학습이 끝나면 4지선다 퀴즈로 오늘 배운 단어를 테스트합니다.
- 퀴즈 결과와 오답 복습 화면을 제공합니다.
- 연속 학습일(스트릭)과 진행률을 브라우저에 저장합니다 (localStorage 사용, 서버/로그인 불필요).

## 실행 방법

빌드 과정이 필요 없는 순수 HTML/CSS/JS 프로젝트입니다. 아래 중 하나로 실행하세요.

```bash
# 방법 1: 파이썬 내장 서버
python3 -m http.server 8000

# 방법 2: Node가 있다면 npx serve
npx serve .
```

이후 브라우저에서 `http://localhost:8000` 에 접속하면 됩니다.
(`index.html`을 파일로 직접 열어도 대부분 정상 동작합니다.)

## 단어 추가하기

`words.js`의 `WORD_BANK` 배열에 `{ en, ko, pos, ex }` 형식으로 항목을 추가하면
자동으로 학습/퀴즈 순환에 포함됩니다. 20개 단위로 나뉘어 매일 순서대로 노출됩니다.
