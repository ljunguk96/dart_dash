# dart_dash

매일 아침 [hk_koreamarket](https://www.youtube.com/@hk_koreamarket) 유튜브 영상을 보고
배운 내용을 요약해서 기록하는 개인 학습 노트 사이트입니다.

## 사용 방법

별도 설치나 서버 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

```
open index.html   # 또는 브라우저에서 직접 파일 열기
```

- 기록은 브라우저의 localStorage에 저장되며, 같은 브라우저/기기에서만 보입니다.
- 날짜, 영상 제목, 영상 링크, 태그, 요약을 입력해 기록을 남길 수 있습니다.
- 검색창으로 제목/요약/태그를 검색할 수 있고, 연속 기록 일수(스트릭)를 상단에서 확인할 수 있습니다.
- 기록은 언제든 수정/삭제할 수 있습니다.

GitHub Pages 등 정적 호스팅에 그대로 배포해도 동작합니다.
